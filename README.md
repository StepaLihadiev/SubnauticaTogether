# Subnautica Together

Русский Windows-лаунчер для первой Subnautica и официального мультиплеерного мода Nitrox. Windows 10/11 x64. Below Zero, Subnautica 2 и legacy-версия первой игры не поддерживаются.

## Установка и запуск

Запустите `artifacts/release/SubnauticaTogetherSetup.exe` либо `artifacts/release/portable/SubnauticaTogether.exe`. SDK не нужен: приложение и bootstrap bridge собраны self-contained. Выберите папку Subnautica, если игра не найдена автоматически, и нажмите «Установить мультиплеер». Лаунчер загрузит официальный архив Nitrox и отдельный runtime .NET 9 с проверкой контрольных сумм. Для первой установки нужен интернет. Установщик не включает игру или Nitrox и не требует прав администратора.

Проверен Nitrox 1.8.1.0 и требования Subnautica build ≥82304. Steam, Epic и доступные XboxGames/Content-установки Microsoft Store поддерживаются адаптером обнаружения. Реальная проверка выполнена только со Steam build 83031. Закрытые WindowsApps/UWP-пакеты не обходятся: выбирайте доступную официальную установку XboxGames. Доступ к Managed-каталогу нужен для официального bootstrap. Другие моды блокируют мультиплеер.

## Игра с другом

«Создать игру»: задайте название, режим, число игроков и UDP-порт. После готовности сервера запускается Subnautica. В игре откройте «Мультиплеер», выберите «Together — друг» и введите имя. Адрес локального хоста добавляется автоматически. Nitrox не предоставляет внешнему лаунчеру автоматический вход в игровую сессию.

Друг выбирает «Подключиться», вводит адрес и порт либо вставляет приглашение. «Проверить адрес» выполняет LiteNetLib UDP handshake с ключом Nitrox; это проверка транспорта. Пароль и совместимость игрового протокола окончательно проверяет официальный клиент. Приглашение содержит адрес, build игры, версию Nitrox и срок 24 часа: оно работает без облака, но не подтверждает личность отправителя и не открывает порты. Версии друзей должны совпадать.

В одной сети используйте LAN-адрес или поиск серверов. Для интернета нужен доступный внешний IP и UDP-правило роутера. UPnP выключен по умолчанию и разрешается флажком при создании мира; mapping выполняет сам Nitrox. Успех mapping не доказывает доступность извне. CGNAT невозможно достоверно определить по одному локальному handshake. Альтернатива — официальный Tailscale: оба игрока устанавливают его, входят в аккаунт и находятся в общей сети; лаунчер проверяет `tailscale status --json`, затем использует Tailscale IP. Автоматической установки Tailscale и авторизации нет.

Собственные relay и rendezvous находятся в `relay/`; публичный сервис не развёрнут. Relay имеет фиксированный upstream, ограничение клиентских IP и проверенный UDP round-trip, но не реализует hole punching. Подробности в `relay/deployment/README.md`.

## Миры, обновления, восстановление

Миры хранятся отдельно от одиночных сохранений. «Мои миры» позволяет запускать, переименовывать, импортировать полные JSON-миры Nitrox той же версии, делать backup и восстанавливать его как новый мир. Работающий мир сначала остановите: backup должен быть согласованным. Удаление требует подтверждения и перемещает мир в `deleted-worlds`, а не стирает его. Резервные копии проверяются по каждому файлу.

«Проверить обновления» получает стабильные релизы GitHub и применяет только проверенные адаптером версии. Перед обновлением мирам создаются копии. Установка использует staging и журнал восстановления; предыдущие сборки сохраняются. Downgrade не выполняется автоматически. Новые неизвестные версии требуют обновления адаптера. Подписанный клиент обновлений самого лаунчера есть; официальный endpoint и ключ публикации пока не настроены.

«Починить» проверяет игру, файлы Nitrox и runtime, повторяет повреждённую установку, восстанавливает интеграцию. Конфликтующие моды и повреждённые оригинальные файлы игра восстанавливает через магазин; лаунчер их не удаляет. «Диагностика» анализирует локальные журналы и экспортирует отчёт с редактированием известных секретов, IP и домашнего пути. Отчёт никуда не отправляется. Проверьте экспорт перед самостоятельной передачей третьим лицам.

Пользовательские данные: `%LOCALAPPDATA%\SubnauticaTogether`. Удаление приложения не удаляет миры, backups или отдельно установленный Nitrox. При закрытии с работающим сервером приложение предлагает безопасное сохранение и остановку; отмена сохраняет сервер работающим.

## Проверенное состояние

См. `docs/STATUS.md`, `docs/TESTING.md`. Создание настоящего Nitrox-мира, localhost UDP handshake, запуск Steam-игры с Nitrox и безопасная остановка проверены. Синхронизация двух игроков, внешний интернет, реальный роутер, Epic/Microsoft Store и игровой relay требуют отдельных проверок. Nitrox остаётся alpha-модом с известными ограничениями синхронизации; это приложение не исправляет сам мод.

Сборка: `./scripts/build.ps1`; тесты: `./scripts/test.ps1`; публикация: `./scripts/publish.ps1`; установщик: `./installer/build-installer.ps1`.

Официальные источники: [Nitrox releases](https://github.com/SubnauticaNitrox/Nitrox/releases), [исходники 1.8.1.0](https://github.com/SubnauticaNitrox/Nitrox/tree/1.8.1.0), [документация](https://subnauticanitrox.github.io/Documentation/). Приложение независимо от Unknown Worlds и команды Nitrox.
