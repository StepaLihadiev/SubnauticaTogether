# Решение проблем

**Игра не найдена.** Выберите каталог с Subnautica.exe, UnityPlayer.dll, Subnautica_Data/globalgamemanagers и Managed/Assembly-CSharp.dll. Лаунчер проверяет PE и тип PlatformUtils, читает build из plastic_status.ignore. Below Zero и Subnautica 2 не подходят. Обновите игру через официальный магазин. XboxGames/Content доступен обычному пользователю; WindowsApps не обходится.

**Версия несовместима или есть моды.** Нужен build ≥82304, чистая установка и проверенный релиз Nitrox. Legacy и совместная работа с QMods/BepInEx запрещены адаптером. Launcher не удаляет моды автоматически. Неизвестный будущий релиз требует обновлённого launcher.

**Загрузка оборвалась.** Повторите установку: cache/*.part используется с HTTP Range, архив затем проверяется полностью. GitHub rate limit использует кэш до 7 дней или показывает время повторного запроса. Без интернета первая установка не выполняется; готовые локальные сборки работают без проверки обновлений.

**Недостаточно места или нет прав.** Выберите пользовательский каталог. Лаунчер не требует повышения прав, но bootstrap должен иметь возможность записать в Managed игры. Нужен запас для старой/новой сборки, архивов, runtime и backups. Символические ссылки/junction в управляемых каталогах не используются.

**Runtime отсутствует/повреждён.** Нажмите «Починить». .NET 10 у launcher не заменяет требование Nitrox к .NET 9. Runtime загружается с Microsoft, проверяется и размещается в отдельном пользовательском каталоге. При временной блокировке файлов выполняются повторные попытки; Defender не отключается.

**Сервер не готов.** Откройте диагностику и журнал. Порт UDP должен быть свободен. Bootstrap сервера зависит от оригинальных ресурсов игры. Автоматический тайм-аут не приводит к потере мира или насильственному завершению. «Остановить сервер» отправляет `stop`; если сохранение затянулось, дождитесь завершения и повторите остановку.

**Друг не подключается.** Сверьте версии Nitrox/build, адрес и UDP-порт. На хосте сначала проверьте localhost. Для LAN найдите адрес сетевой карты; для интернета проверьте реальный внешний адрес/UDP mapping со второго хоста. CGNAT может исключать прямой inbound. UPnP только пытается настроить роутер; его успех не равен доступности. Используйте общую Tailscale-сеть и её IP, если прямой маршрут отсутствует. Не отключайте firewall/антивирус.

**Игра запускается, но multiplayer не появился.** Проверьте наличие bridge в каталоге launcher, checksum Nitrox и игровые журналы в NitroxData/logs. Нужны сообщения `Completed patching` и `Behaviours applied`. Steam должен корректно запускать вашу лицензионную копию; сообщения `Couldn't initialize Steamworks`/`Missing Steam DRM` требуют проверки исходных файлов и платформы через Steam. Launcher не исправляет DRM и не подменяет игровые файлы сторонними копиями. Ошибка Discord hook не доказывает отказ multiplayer.

**Мир повреждён.** Остановите сервер, выберите ZIP backup и восстановите его как отдельный мир. Не заменяйте существующие данные. Копии из других версий не конвертируются автоматически. Удалённые через UI миры лежат в deleted-worlds. Удаление самого launcher не трогает пользовательские каталоги.

**Откат установки.** Не удаляйте install-journal.json и sibling `.previous-*` вручную во время recovery. Следующий запуск восстановит предыдущую согласованную установку. Если требуется ручное восстановление, сначала скопируйте data root и backups целиком. `.failed-*` и `.stage-*` сохраняются для анализа.
